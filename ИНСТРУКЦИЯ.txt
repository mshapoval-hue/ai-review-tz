AI-РЕВЬЮ ТЗ — ЧТО ДЕЛАТЬ

ЧАСТЬ 1. Один раз обновить GitHub

В репозитории ai-review-tz заменить:
1) app.js — файлом app.js из этого архива.
2) Добавить новый файл config.json.

После Commit GitHub Pages обновится автоматически.

ЧАСТЬ 2. Запуск Bridge на компьютере

1) Создайте папку, например:
   C:\AI-Review-Bridge

2) Положите туда:
   AI-Review-Bridge.ps1
   START_AI_REVIEW_BRIDGE.bat

3) Дважды нажмите:
   START_AI_REVIEW_BRIDGE.bat

4) Должно открыться черное окно с текстом:
   AI Review Bridge запущен.
   Адрес: http://127.0.0.1:8765

5) Не закрывайте это окно во время проверки ТЗ.

6) Откройте:
   https://mshapoval-hue.github.io/ai-review-tz/

7) Загрузите DOCX и нажмите «Запустить ревью».

КАК ОБНОВЛЯТЬ ВЕРСИЮ БОТА

Если в MWS появилась новая версия, например 1492:
1) открыть config.json в GitHub;
2) заменить:
   "projectVersionId": 1491
   на:
   "projectVersionId": 1492
3) Commit changes.

У аналитиков ничего переустанавливать не нужно.
Bridge читает config.json заново при каждой проверке.

ВАЖНО

Этот Bridge рассчитан на работу на компьютере, который имеет доступ
к корпоративному MWS-стенду.

Если MWS потребует отдельную серверную авторизацию, первый тест покажет это
по коду HTTP-ошибки, и Bridge можно будет скорректировать.
