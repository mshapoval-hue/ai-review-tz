# AI-ревью ТЗ — GitHub Pages UI

Это готовый статический интерфейс для публикации через GitHub Pages.

## Сейчас

Интерфейс работает в демо-режиме:
- можно выбрать DOCX;
- проверить валидацию формата;
- увидеть progress flow;
- увидеть пример отчета;
- скачать demo-отчет.

## Следующий этап

Подключить кнопку «Запустить ревью» к MWS AI Agents через безопасный backend/proxy.

GitHub Pages сам по себе не должен хранить MWS token/cookie.
